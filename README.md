# AI-IDE 🚀

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

**AI-IDE** — это современная интегрированная среда разработки (IDE), вдохновленная VS Code, но спроектированная с упором на нативную интеграцию искусственного интеллекта. 

Главная особенность редактора — возможность **самостоятельно загружать и подключать API любых нейросетей** (OpenAI, Anthropic, Gemini, локальные модели через Ollama/LM Studio и другие) для помощи в написании кода, рефакторинге и анализе архитектуры.

## ✨ Ключевые особенности

- 💻 **Знакомый интерфейс:** Если вы работали в VS Code, вы почувствуете себя как дома. Привычные горячие клавиши, древо файлов и управление вкладками.
- 🧠 **Ваш собственный ИИ:** Редактор не привязывает вас к одной нейросети. Вставьте свой API-ключ от любимой языковой модели и используйте её без ограничений.
- ⚡ **Умный ассистент:** Генерация кода по текстовому описанию, автоматический поиск багов, написание тестов и документации в один клик.
- 🔌 **Гибкая настройка API:** Поддержка custom-endpoint'ов. Вы можете подключить даже собственную локально развернутую модель.
- 🎨 **Кастомизация:** Поддержка тем оформления и базовых расширений.

## 🚀 Установка и запуск

*(Здесь вы можете указать реальные команды для вашего стека, например, npm/yarn или python)*

```bash
# 1. Клонируйте репозиторий
git clone [https://github.com/George5556/AI-IDE.git](https://github.com/George5556/AI-IDE.git)

# 2. Перейдите в папку проекта
cd AI-IDE

# 3. Установите зависимости (пример для Node.js)
npm install

# 4. Запустите проект
npm start
